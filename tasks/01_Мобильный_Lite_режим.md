# Задача 01: Идеальный свайп мобильного Канбана (как в TickTick)

## 🎯 Цель
Сделать так, чтобы в мобильном портретном режиме Канбан-доска переключала колонки (вкладки) плавным свайпом пальца по всему экрану (по фону), а не только по верхним табам. При этом свайп не должен конфликтовать с открытием бокового меню и скроллом вверх-вниз.

## 🛠️ Техническое задание
1. Открой `board.component.ts` и `board.component.html`.
2. Найди существующую в проекте `SwipeDirective` (или аналогичный механизм свайпа, который используется для карточек задач) и примени её к контейнеру, в котором отображается активная колонка (или ко всему фону доски) в портретном режиме.
3. Если директива не подходит, напиши логику на PointerEvents (pointerdown, pointermove, pointerup):
   - При pointerdown запоминай `pageX`.
   - При pointerup вычисляй `dx = pageX - startX`. Если `dx > 50` — переключай на предыдущую колонку (`selectMobilePanel`), если `dx < -50` — на следующую.
   - Обязательно вызывай `event.stopPropagation()` при pointerdown, чтобы глобальный свайп (MagicSideNav) не открывал боковое меню.
4. Убедись, что вертикальный скролл (вверх-вниз) не блокируется. Если палец двигается больше по Y, чем по X, отдавай событие браузеру для обычного скролла.
5. В `board.component.scss` верни `touch-action: pan-y;` для контейнера доски, чтобы нативный вертикальный скролл работал идеально, а горизонтальный мы перехватывали руками.

Сгенерируй диффы.
