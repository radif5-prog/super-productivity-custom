# Задача 04: Выравнивание списка задач по левому краю

## 🎯 Цель

Сейчас список задач отображается узкой колонкой по центру экрана. Нужно сделать так, чтобы список занимал больше ширины и был выровнен по левому краю (или имел более широкий max-width), как в TickTick или Notion.

## 🛠️ Техническое задание

1. Найди SCSS-файл, который задает ширину и выравнивание контейнера со списком задач (скорее всего, это `task-list.component.scss` или `project.component.scss`).
2. Найди класс-обертку (например, `.task-list`, `.task-list-wrapper` или `.main-content`), у которого задано `margin: 0 auto;` и `max-width: 600px` (или около того).
3. Измени это поведение:
   - Убери центрирование `margin: 0 auto;` (или замени на `margin: 0;`).
   - Увеличь `max-width` до `900px` (или `100%`, чтобы список растягивался на доступную ширину).
   - Добавь `padding-left: 24px;` (или аналогичный отступ), чтобы текст не прилипал к левой панели меню.
4. Убедись, что на мобильных устройствах (где `isXs() === true`) список по-прежнему занимает 100% ширины и выглядит хорошо.

Сгенерируй диффы.
