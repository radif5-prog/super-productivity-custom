# Задача 05: Выравнивание родительского контейнера списка по левому краю

## 🎯 Цель

Список задач всё еще отображается по центру экрана, так как его родительский контейнер центрирует содержимое. Нужно прижать список к левому краю (сразу после бокового меню).

## 🛠️ Техническое задание

1. Найди родительский контейнер, который оборачивает компонент `<task-list>`. Скорее всего, это файлы `project.component.scss`, `work-view.component.scss` или стили для `.main-content` / `.work-context`.
2. Найди там свойства, которые центрируют контент: `margin: 0 auto;`, `justify-content: center;`, `align-items: center;` или `display: flex` с центрированием.
3. Измени их так, чтобы контент прижимался к левому краю:
   - Замени `margin: 0 auto` на `margin: 0;` или `margin-left: 0;`.
   - Если используется flexbox, замени `justify-content: center` на `justify-content: flex-start`.
   - Если у контейнера задан маленький `max-width`, удали его или увеличь до `100%` (но оставь `max-width: 900px` у самого компонента `task-list`, который мы настроили ранее).
4. Убедись, что на мобильных устройствах ничего не поехало.

Сгенерируй диффы.
